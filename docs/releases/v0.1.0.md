# Glowcast v0.1.0

The first release of Glowcast, an early version.

## What it does

Glowcast is a Home Assistant custom integration that lets your Philips Hue lights follow the picture on an LG webOS TV. It grabs frames from the TV over its local network API, works out the average colour of each part of the screen and streams those colours to a Hue entertainment area, including gradient lightstrips segment by segment. No subscription, no HDMI box, and everything stays on your local network.

- Reuses Home Assistant's existing LG webOS pairing: no extra prompt on the TV.
- Streams to an entertainment area you set up in the Hue app, up to 25 times per second, fading smoothly between frames.
- One switch to start and stop syncing; the lights return to how they were when it stops.
- Settings: entertainment area, brightness (1-100 %, default 80 %), intensity (0-200 %, default 100 %) and update rate (Low, Medium, High (default) or Maximum: 1, 2, 3 or as many captures per second as the TV allows).
- On a black picture the lights keep a faint warm glow instead of going dark.
- English and Dutch.

## Requirements

- Home Assistant 2025.7.2 or newer
- An LG TV running webOS, set up in Home Assistant with the **LG webOS Smart TV** integration
- A Philips Hue Bridge v2 or Hue Bridge Pro, set up in Home Assistant with the **Philips Hue** integration, with an entertainment area set up in the Hue app (Hue app → Settings → Entertainment areas)
- [HACS](https://hacs.xyz/)

## Installation

Glowcast is not in the default HACS list yet; add it as a custom repository:

1. Open **HACS**, then the menu (⋮) in the top right corner → **Custom repositories**.
2. Enter `https://github.com/nicohabets/glowcast` as the repository, choose type **Integration** and click **Add**. Close the dialog.
3. Search for **Glowcast**, open it and click **Download**, then **Download** again in the dialog.
4. Restart Home Assistant.
5. Go to **Settings → Devices & services → Add integration → Glowcast**.

During setup you pick the TV, the Hue bridge (press its link button when asked; Glowcast pairs once itself, because streaming needs a key that Home Assistant's own Hue connection does not have) and the entertainment area. Brightness, intensity, update rate and the area can be changed later under **Configure**.

From Home Assistant 2026.11, HACS is built into Home Assistant as **Settings → Marketplace**; these steps were checked with HACS on Home Assistant 2026.10.

## The switch

Glowcast adds one device, "Glowcast *TV name*", with one switch, for example `switch.glowcast_living_room_tv`. Turn it on to start syncing and off to stop. Glowcast never starts by itself: the switch is off after a restart of Home Assistant. It turns off by itself when the TV turns off, when another app is already streaming to the bridge, or when the stream is lost; the reason is in the Home Assistant log.

Start it from a dashboard, by voice or with an automation, for example when the TV turns on:

```yaml
triggers:
  - trigger: state
    entity_id: media_player.living_room_tv
    from: "off"
    to: "on"
actions:
  - action: switch.turn_on
    target:
      entity_id: switch.glowcast_living_room_tv
```

Glowcast waits up to 10 seconds for the TV to show a picture, so it can start the moment the TV reports "on".

## Known limits

- **About 3 captures per second.** That is the TV's capture limit: fine as ambient light, but not as fast as an HDMI sync box.
- **Streaming apps with DRM in the TV's own apps return a black picture** (tested with Prime Video), so the lights show only the faint glow. The same app on a streaming stick over HDMI works.
- **The TV's capture call is undocumented** by LG and could stop working after a TV firmware update.
- **One stream per bridge at a time.** Two TVs on one bridge cannot sync together, and Glowcast does not start while another app (Hue Sync, a Sync Box) is streaming.
- **Changing a setting while syncing** briefly restarts the light stream.
- **TV lightstrip segments sample about 30 % in from the picture's edges**, not the edges themselves (#23).
- **Glowcast's icon** only shows in Home Assistant 2026.3 or newer.

## Privacy

Frames are kept in memory only and are never stored or sent anywhere; everything stays on your local network. Glowcast pairs with your Hue bridge once and stores that key in Home Assistant; like any app connected to the bridge, the key gives full access to it. After removing Glowcast you can also remove it from the bridge: in the Hue app, go to **Settings → Apps → Network-based**, tap the info button next to **glowcast** and remove it.
