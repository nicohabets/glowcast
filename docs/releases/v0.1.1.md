# Glowcast v0.1.1

A small update to v0.1.0, an early version.

## What changed

- **Saturated colours stay pure.** The faint warm glow is now only added to lights that show a dark part of the picture. Before, it was mixed into every colour, so a blue scene at low brightness looked lilac and a red one pinkish. On a black picture the glow is the same as in v0.1.0 (#43).
- **The page in HACS looks right.** HACS shows Glowcast's icon at the top of its page instead of raw HTML and a broken image, and the links in the README work there (#59).
- **Preparing for the default HACS list.** The README says Glowcast is being submitted to the default HACS list. Until it is listed, install it as a custom repository (#48).
- Inside: the colour state moved out of the pipeline into its own class, and the tests share one set of fakes (#65, #62). No change in behaviour.

## Upgrading from v0.1.0

Update Glowcast in HACS (or under Settings → System → Updates) and restart Home Assistant. Your settings stay as they are.

## Requirements and installation

The same as v0.1.0: Home Assistant 2025.7.2 or newer, an LG webOS TV and a Hue Bridge v2 or Bridge Pro with an entertainment area, both set up in Home Assistant. See the [README](https://github.com/nicohabets/glowcast#installation) for the installation steps and the [v0.1.0 release notes](https://github.com/nicohabets/glowcast/blob/main/docs/releases/v0.1.0.md) for everything Glowcast does and its known limits.
